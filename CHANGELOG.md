# Изменения

## 0.1.0 — первый выпуск

- Spotify на колонке с голосовым управлением: «включи песню / группу / альбом X»,
  «дальше», «назад», «пауза», «громче», «что играет», «N песен назад»,
  «ты поставила не то», чёрный список.
- Радио: после первого трека — ещё того же исполнителя (без повторов за сутки),
  потом из избранного.
- Поиск токеном владельца аккаунта (как в приложении, прощает опечатки), каталог —
  по стране аккаунта.
- Монитор `:28088`: что играет, очередь, история, поиск с подсказками, чёрный
  список, настройки, редактор голосовых команд.
- Свой регулятор громкости музыки: следует за громкостью ассистента и приглушается,
  пока он говорит.
- Свои реплики ассистент читает разными формулировками, без одной постоянной фразы.
- Громкость и название в одной фразе («X громкость 5», «громкость 5 X»): громкость
  ставит ассистент, X включается в Spotify.
- Установщик и удалятор по adb; пакеты с готовыми бинарями для armv7 и aarch64,
  сборка из исходников, если пакет не под ту архитектуру.
